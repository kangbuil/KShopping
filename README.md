# 🛒 쇼핑리스트

Streamlit으로 만든 간단한 쇼핑리스트 웹 앱입니다. 장볼 품목을 추가·수정·삭제하고, 구매하면 체크할 수 있습니다.

## 기능
- **추가**: 입력창에 품목을 적고 Enter 또는 `➕ 추가` (공백만 입력하면 추가되지 않음)
- **수정**: ✏️ 버튼으로 이름 변경 후 저장/취소
- **삭제**: 🗑️ 버튼으로 항목 삭제
- **체크**: 체크박스로 구매 완료 표시 (완료 항목은 취소선)
- **전체 선택/해제**: 목록 위 체크박스로 모든 항목을 한 번에 완료/미완료 처리
- **요약**: 진행률 바와 "남은 항목 N / 전체 M"
- **완료 항목 삭제**: 체크된 항목을 한 번에 삭제
- **자동 저장**: 변경 사항이 `items.json`에 저장되어 재실행 후에도 유지
- 모바일 화면과 다크 모드 지원

## 실행 방법
Python 3.9 이상이 필요합니다.

```bash
pip install -r requirements.txt
streamlit run app.py
```

브라우저에서 http://localhost:8501 로 접속합니다.

## 파일 구성
| 파일 | 설명 |
|---|---|
| `app.py` | 앱 본체 |
| `requirements.txt` | 의존성 (`streamlit`) |
| `.streamlit/config.toml` | 테마 설정 |
| `prd.md` | 제품 요구사항 문서 |
| `items.json` | 실행 중 자동 생성되는 데이터 파일 (Git 제외) |

## 데이터 저장 관련 주의
데이터는 서버의 로컬 파일 `items.json`에 저장됩니다.

- 혼자 로컬 PC에서 쓰는 용도에 맞게 만들어져 있습니다.
- Streamlit Community Cloud 같은 곳에 배포하면 앱이 재시작될 때 데이터가 사라질 수 있고, 모든 접속자가 같은 목록을 공유합니다.
